Before you start: who can see it

On GitHub’s free plan the repository has to be public, and a GitHub Pages site can be opened by anyone who has its address, even when the repository is private. Only GitHub Enterprise Cloud can limit a Pages site to signed-in members of an organisation.

So the library’s own text (deck names, use cases, the notes on what is live, in development or proposed) becomes readable to anyone with the link. The decks and PDFs themselves stay in Google Drive behind DOKU sign-in, and every page tells search engines not to index it. If DOKU has a GitHub Enterprise organisation, create the repository there and ask its admin to make the Pages site private.

    Troubleshooting

    The fixes for what usually goes wrong.

    GitHub says “Yowza, that’s a lot of files” or refuses the upload

    That upload had more than 100 files: two batches were dragged at once, or a whole folder above them. Upload one UPLOAD folder’s contents at a time.

    I see a folder called UPLOAD-1 in my repository

    The folder was dragged instead of what is inside it, so the files sit one level too deep. The quickest fix is to start the repository again:

    1. Open , scroll to Danger Zone and click Delete this repository.
    2. Repeat steps 2 to 4, dragging the contents of each UPLOAD folder.
    The site address shows a 404 page

    Give the first publish two or three minutes after the green tick. Then check that the Pages settings say main and / (root), and that index.html is at the top level of the repository. The repository part of the address must match its name exactly.

    Some pictures are missing

    One picture batch wasn’t committed. Compare the repository with the list in step 5 and upload the missing UPLOAD folder again.

    Pages asks me to upgrade, or the branch menu is greyed out

    On the free plan Pages only works with public repositories. Make the repository public in Settings under Danger Zone, Change visibility, or use a plan with private Pages.

    I can’t see the Settings tab

    You need admin rights on the repository. Ask the organisation owner, or create the repository under your own account.

    A video won’t play

    Some office networks block video streaming. Try another network. The Drive button under each video still opens the film in Google Drive.

    Google Drive asks for access

    The decks keep their Drive sharing. Sign in with your DOKU Google account, or request access from the file owner.

    My change doesn’t show

    Wait about a minute for the publish run, then force a refresh: Ctrl+F5 on Windows, Cmd+Shift+R on Mac.
